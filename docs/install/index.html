Install Delta Review

Chrome and Edge

Install the unpacked build

The same steps on Windows, macOS, Linux and ChromeOS. No administrator needed.

  1. Download the zip and unzip it somewhere permanent — do not move or delete it later.
  2. Open chrome://extensions (or edge://extensions).
  3. Turn on Developer mode.
  4. Click "Load unpacked" and choose the unzipped folder.

Installed this way, Delta does not update itself — repeat to upgrade.

Windows: install by policy, and keep it updated

Chrome does not allow installing from a link without a one-time setup step. Run this once in PowerShell — no admin rights needed — then restart the browser. Delta installs itself and stays up to date. 


        

          Managed devices sometimes ignore per-user policy. If Delta has not
          appeared after a restart, use the unpacked build instead.
        

      


      

        On macOS, Linux and ChromeOS a self-updating install comes from a
        policy your administrator applies — a configuration profile, or a JSON
        file in the browser's managed-policies directory — not from anything
        you can run yourself. The unpacked build above needs none of that.

After installing

      

        Click the Delta icon, open Settings, and add your GitLab host with a
        personal access token that has the api scope. Give the
        token an expiry date. Delta only ever asks for permission to reach the
        hosts you add.
