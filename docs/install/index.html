Install Delta Review

Chrome and Edge

Chrome does not allow installing from a link without a one-time setup step. Run this once in PowerShell — no admin rights needed — then restart the browser. Delta installs itself and stays up to date.

Managed devices sometimes ignore per-user policy. In that case:

        
    
          
  1. 
            
              Download the zip
            
            and unzip it somewhere permanent — do not move or delete it later.
          
    2. 
          
  2. Open chrome://extensions (or edge://extensions).
    3. 
          
  3. Turn on Developer mode.
    4. 
          
  4. Click "Load unpacked" and choose the unzipped folder.
    5. 
        

        
Installed this way, Delta does not update itself — repeat to upgrade.

      

    


    

      
After installing

      

        Click the Delta icon, open Settings, and add your GitLab host with a
        personal access token that has the api scope. Give the
        token an expiry date. Delta only ever asks for permission to reach the
        hosts you add.
